Мастерская модальных окон

Выберите задачу и реализуйте её с помощью JavaScript.

Список задач

01

Базовое модальное окно

Создайте простое модальное окно, которое открывается по нажатию кнопки и закрывается по клику на крестик.

02

Окно с фоном-оверлеем

Модальное окно должно открываться с затемнённым фоном (оверлеем), который также закрывает окно при клике на него.

03

Окно с анимацией

Реализуйте плавное появление и скрытие модального окна с использованием анимации (например, fade-in и scale).

04

Закрытие по клавише Escape

Добавьте возможность закрывать активное модальное окно нажатием клавиши Escape на клавиатуре.

05

Модальное окно с формой

Создайте модальное окно, содержащее форму. При нажатии на кнопку "Отправить" окно должно закрываться, а данные выводиться в консоль.

Подсказка по реализации: Все кнопки для открытия имеют класс open-modal-btn и атрибут data-modal-target с селектором нужного модального окна. Структура самих окон находится в конце body.

Не редактируйте HTML и CSS для выполнения задач. Вся логика пишется в отдельном JS-файле.
